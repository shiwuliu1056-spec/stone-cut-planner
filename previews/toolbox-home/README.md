# 宝松工具箱 · 首页视觉预览

直接打开 `index.html`，或用本地静态服务器查看。零安装、无构建步骤；所有样式和 SVG 均在本目录，不访问远程资源、不调用任何业务接口。

这是手机首页外观原型，不是已接入的小程序：首页按钮提供按压和键盘焦点反馈，支持浏览器震动API时每次点击请求10ms轻震动，不跳转。未支持震动的设备不报错；物理震感尚未真机验证。手机状态栏、微信胶囊和底部手势条为展示外壳，不是业务按钮。正式接入小程序时，三个入口沿用 `wx.vibrateShort({ type: 'light' })`。

## 设计规格

- 目的：让用户首屏看清三个工具及用途，替换底部工具切换的入口设计。
- 风格：精致工具目录，左侧文字与右侧几何线条插画形成非对称构图；工具视觉分量一致。
- 配色：现有深绿 `#173e38`、黄铜 `#c99352`、暖白 `#f7f5f0`、深墨绿 `#20332f`、灰绿 `#7b8883`。
- 字体：沿用项目中文字体，优先 PingFang SC，再 Microsoft YaHei，不下载外部字体。这是对设计技能默认字体限制的品牌延续例外。
- 手机基准：390 × 844；兼容性检查宽度375和430像素。三张卡片等高148px，间距13px。
- 起诉助手保留适用范围：九江 · 买卖合同纠纷。
- 标语：拥抱AI  提高效率。
- 每张卡片采用三列布局：左侧窄编号列（01/02/03仍靠左上角）、中间统一左对齐且整组上下居中的名称/用途/适用范围、右侧缩小并上下居中的自绘SVG插画。列间保留10–12px间距，不显示分类或箭头。

## 范围

本目录不修改小程序、后端、现有业务数据或部署配置。没有创建工作树，也没有发布。下一步视觉确认后，再单独接入入口导航和起诉助手分包。

## 验证

在项目根目录启动预览服务器：

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory previews/toolbox-home
```

在另一终端执行 `node previews/toolbox-home/verify.mjs`。需要本机已有 Playwright 和 Chromium；若 Playwright 不在当前模块搜索路径，可通过 `PLAYWRIGHT_MODULE` 指定其 `index.mjs` 的绝对路径。

验证覆盖三列独立间距、编号左上角、文字统一左对齐且整组上下居中、图标上下居中、无分类与箭头、新标语、首屏完整、图文边界、横向溢出、按压反馈、键盘焦点、三入口各触发单次震动请求、不支持震动API时正常、无跳转、无外部请求和无浏览器错误。震动API使用测试替身确认调用，不能证明设备有物理震感。输出 `home-375.png`、`home-390.png`、`home-430.png`；本预览不涉及微信真机功能验证。
