# Word rendering font

NotoSerifCJKsc-Regular.otf is bundled solely for the server's private rendering and pagination checks. It is not uploaded to any AI provider.

Source: https://github.com/notofonts/noto-cjk/blob/main/Serif/OTF/SimplifiedChinese/NotoSerifCJKsc-Regular.otf

License: SIL Open Font License 1.1, included in OFL.txt.

On macOS the document uses the existing Songti SC font for WPS compatibility. Linux uses Noto Serif CJK SC. CLAIM_WORD_FONT can select a deployed font. Page references use native Word bookmarks and remain updateable after edits.
